# Red LAN Simple - Cisco Packet Tracer

## 📌 Descripción
Mi primer proyecto de red de área local. Consta de 4 computadoras conectadas a un switch, todas en la red 192.168.1.0/24.

## 🛠️ Herramientas utilizadas
- Cisco Packet Tracer

## 📋 Topología
4 PCs conectadas a un switch 2960 mediante cables de cobre rectos.

## 🔢 Direccionamiento IP

PC0: 192.168.1.10
PC1: 192.168.1.11
PC2: 192.168.1.12
PC3: 192.168.1.13

## ✅ Prueba
Se comprobó la conectividad exitosa mediante el comando ping.
